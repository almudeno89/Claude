## Proposed commercial arrangement

We would operate a branded web application using an operator-funded, server-side
Higgsfield API workspace. Customers would buy our application's prepaid credits at a
markup over our generation costs. We would debit those credits when they generate images
or videos. We also want the option of monthly/annual subscriptions containing credits and
one-time top-ups. These customer credits would be our own ledger entries, not transfers of
Higgsfield prepaid units. Exact credit prices, markup, volumes and subscription allowances
remain to be agreed; we are not representing any minimum commitment.

Customers would submit prompts and optional reference media, choose an approved model
and settings, and download results. Planned workflow features include projects, reusable
presets, generation history and an asset library. Community publishing and Recreate are
later candidates. We understand that these features do not automatically satisfy section
4.1 or authorize resale under section 4.2. There would be no customer-facing raw API,
provider key access or independent model-access API.
